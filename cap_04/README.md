# cap_04 — Módulo 5: Construindo Agentes com LangGraph

## Objetivo
Dominar StateGraph, Checkpoints, Memória de Curto/Longo Prazo e
Human-in-the-Loop (HITL) com um Finance Bot como projeto central.

## Setup
```bash
source cap_04/.myenv/bin/activate
pip install -r cap_04/requirements-cap04.txt
```

## Projeto Principal
| Arquivo | Descrição |
|---|---|
| `projeto/finance_bot.py` | Finance Bot com memória, HITL e checkpointing |
