# cap_03 — Módulo 4: LangChain e LCEL na Prática

## Objetivo
Dominar a LangChain Expression Language (LCEL) para construir pipelines
compostos e um assistente de codificação auto-corretivo.

## Setup
```bash
source cap_03/.myenv/bin/activate
pip install -r cap_03/requirements-cap03.txt
```

## Projeto Principal
| Arquivo | Descrição |
|---|---|
| `projeto/assistente_codigo.py` | Pipeline LCEL: geração → validação → correção de código |
